# CodeAlpha Internship Projects

This repository contains projects developed as part of my **CodeAlpha Internship**, showcasing my skills in Python development, web technologies, and Natural Language Processing (NLP).

## Projects

### 1. Language Translator
A web-based application that allows users to translate text between different languages through a simple and user-friendly interface.

**Features:**
- Enter text for translation.
- Select source and target languages.
- Display translated text.
- Copy translated text for easy use.

**Technologies:** Python, Django, HTML, CSS, JavaScript, Translation API.

### 2. ShopMate – E-commerce Chatbot
An intelligent FAQ chatbot designed to answer common e-commerce customer queries automatically. It uses Natural Language Processing and text similarity techniques to identify relevant answers.

**Features:**
- Automated responses to frequently asked questions.
- Handles common queries, such as order tracking.
- Uses text preprocessing and TF-IDF vectorization.
- Matches user queries using cosine similarity.

**Technologies:** Python, Flask, NLTK, Scikit-learn, TF-IDF, Cosine Similarity.
